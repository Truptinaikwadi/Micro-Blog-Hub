MicroBlogHub 📝
A Weibo-like Microblogging Web Application built using Django and MySQL

📌 Project Overview
MicroBlogHub is a social microblogging platform inspired by Weibo.
Users can:

Register and log in
Create short text posts
View posts from other users
Manage profiles
The project is developed collaboratively and uses a shared MySQL database for all contributors.
🛠️ Tech Stack
Backend: Django (Python)
Database: MySQL
Frontend: HTML, CSS (Django Templates)
Version Control: Git & GitHub
Environment: Virtual Environment (venv)
